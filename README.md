# Урсус Бул

Website for veterinary practice Урсус Бул in Sofia, Bulgaria.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd ursus-bul
npm i
npm run dev
```

## Deployment

The site is prerendered and published to GitHub Pages automatically from the
`main` branch.
